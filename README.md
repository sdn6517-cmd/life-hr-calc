# 생활 계산소 — 출산·육아 지원금 · 퇴직금 · 실업급여 계산기

2026년 기준 한국 출산·육아 지원금과 직장인 정산(퇴직금·연차수당·실업급여)을 한 페이지에 모은 정적 웹앱입니다.
빌드 도구·의존성 없이 `index.html` 하나로 동작하며, GitHub Pages에 그대로 배포할 수 있습니다.

- 기준일: 2026-11-15
- 구성: 계산기 4종(출산·육아 통합, 2027 개편 미리보기, 퇴직금·연차수당, 실업급여)

## 구성

```
index.html      계산기 3탭 + 해설 + FAQ (단일 진입점)
styles.css      모바일 우선 반응형 스타일 (Pretendard CDN)
app.js          계산 엔진 + UI (순수 함수는 window.LHC 로 노출)
privacy.html    개인정보처리방침 (쿠키·제3자 광고 고지)
about.html      서비스 소개·계산 기준·면책·문의
sitemap.xml     검색엔진용 사이트맵
robots.txt      크롤러 정책 (AdSense 크롤러 허용)
og-image.png    OpenGraph 공유 이미지 (1200×630)
tests/          계산 엔진 자동 검증 (QuickJS / 브라우저)
```

## 계산기

1. **출산·육아 지원금 통합** — 첫만남이용권(첫째 200만·둘째 이상 300만), 부모급여 24개월(0세 100만·1세 50만, 어린이집 차액), 아동수당 24개월(월 10만~13만, 지역 가산), 육아휴직급여(일반 250/200/160만, 하한 70만)와 6+6 부모육아휴직제(250~450만) 월별 비교
2. **2027 개편 미리보기** — 아이맞이지원금(1,000/1,200/1,500만 + 우대지역 500만)·아동기본수당(월 20만·우대 30만·0~1세 가정보육 +30만) 정부안을 24개월로 환산해 2026년 제도와 비교
3. **퇴직금·연차수당** — 입사일·마지막 근무일, 3개월 임금, 정기 상여금(3/12), 기지급 연차수당(3/12), 통상임금(209시간)으로 평균임금·법정 퇴직금·미사용 연차수당 계산. 평균임금 < 통상임금이면 통상임금 적용
4. **실업급여** — 만 나이·장애 여부·고용보험 가입기간·이직 전 3개월 임금으로 1일 구직급여액(2026 상한 68,100원·하한 66,048원), 소정급여일수(120~270일), 총 예상 수급액 계산

## 광고 코드 넣는 곳

| 지면 | 위치 | id |
| --- | --- | --- |
| 상단 | 계산기 위 | `#ad-slot-top` |
| 본문 중간 | 계산기와 해설 사이 | `#ad-slot-infeed` |
| 하단 | 본문 끝 | `#ad-slot-bottom` |

1. **Google AdSense** — `index.html` 의 `</head>` 직전 주석에 있는 로더 스크립트를 풀고
   `ca-pub-XXXXXXXXXXXXXXXX` 을 실제 게시자 ID로 바꿉니다. 각 지면의 `.ad-inner` 안에
   `<ins class="adsbygoogle" ...></ins>` 와 `(adsbygoogle = window.adsbygoogle || []).push({});` 를 넣습니다.
2. **Taboola / MGID** — `</body>` 직전에 사업자 스크립트를 한 번 넣고, 각 지면의 `.ad-inner` 안에
   해당 위젯 컨테이너를 넣습니다.
3. 승인 전에는 지면이 점선 자리표시자로 보이며, 빈 광고 코드는 넣지 않았습니다.
4. 승인 후 루트에 `ads.txt` 를 만들고 `google.com, pub-XXXXXXXXXXXXXXXX, DIRECT, f08c47fec0942fa0` 한 줄을 넣으면 됩니다.
